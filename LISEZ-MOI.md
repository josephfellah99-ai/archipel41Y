# Installateur Windows d'Archipel41 1.0.0

GitHub limite la taille des fichiers : l'installateur (153 Mo) est donc découpé en deux morceaux.

1. Sur cette page, cliquez sur le bouton vert **Code**, puis **Download ZIP**.
2. Ouvrez le dossier **Téléchargements**, faites un clic droit sur le fichier ZIP › **Extraire tout…** › **Extraire**.
3. Dans le dossier extrait, double-cliquez sur **INSTALLER_ARCHIPEL41.bat**.
   - Si Windows affiche « Windows a protégé votre ordinateur » : **Informations complémentaires** › **Exécuter quand même**.
4. Le script rassemble les deux morceaux, vérifie le fichier (empreinte SHA-256) puis lance l'installation d'Archipel41.

Empreinte SHA-256 de l'installateur : `5751053d09b77aed647c20768b44fc749f2759b25476ab3e8741ad7f8593af81`

Le code source complet se trouve sur la branche `main`.
